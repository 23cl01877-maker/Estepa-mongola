# Maqueta Estepa Mongola

Modelos 3D interactivos (HTML + Three.js) de una maqueta de palillos de madera.

**Ver en línea:** https://23cl01877-maker.github.io/Estepa-mongola/

| Modelo | Archivo |
|---|---|
| Paisaje del clan | `Maqueta_Palillos/paisaje_clan.html` |
| Centro de reunión áureo | `Maqueta_Palillos/palillos_espiral_aurea.html` |
| Puente de Leonardo (v3) | `Maqueta_Palillos/puente/puente_davinci_v3.html` |
| Conector tetradecaedro | `Maqueta_Palillos/conector_tetradecaedro.html` |
| Quiosco hexagonal | `Maqueta_Palillos/quiosco_hexagonal.html` |

Más: `Guia_de_uso.pdf` (guía con capturas), `conector_tetradecaedro/` (OpenSCAD y STL del conector), `Maqueta_Quiosco/` (fotos y entrega del quiosco).

## Uso local

Abrir cualquier `.html` en un navegador moderno. Requiere internet la primera vez (las librerías Three.js se cargan desde unpkg.com). Las páginas deben conservar su posición dentro de la carpeta: los logos se buscan en `assets/logos/`.
